[full-duplex literature survey](../../full-duplex-recent-literature.md). Each

links to the canonical abstract and revision history.

does not relicense them. Consult the license shown on each arXiv abstract page
before redistributing a paper outside this repository.

## Integrity and updates

Verify the archive from this directory with:

```bash
shasum -a 256 -c SHA256SUMS
```

Do not overwrite an existing file when arXiv publishes another revision. Add
the new versioned PDF, retain the old one for stable references, and update
this index plus `SHA256SUMS`.
