# Getting Started

## Prerequisites

- macOS on Apple Silicon
- A supported coding CLI ([Claude Code](https://docs.anthropic.com/en/docs/claude-code),
  [Gemini CLI](https://github.com/google-gemini/gemini-cli),
  [Codex](https://github.com/openai/codex), or
  [OpenCode](https://github.com/anthropics/opencode))
- [geno-tools](https://github.com/42euge/geno-tools) installed

## Installation

Install via geno-tools:

```bash
geno-tools install geno-voice
```

Or from within an agent session:

```
/geno-tools install geno-voice
```

## First use

Once installed, the geno-voice skill is available in your agent session. The
voice pipeline components (STT, TTS, VAD) can be used by other geno-ecosystem
projects that need voice interaction capabilities.
