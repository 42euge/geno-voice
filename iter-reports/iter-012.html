Notes:

  • The faked-LLM orchestration test runs in 150ms. Production behavior is identical because the same components compose the same way — the test just stubs out the HTTP transport.
  • The "event set before cancel returns" test was tricky to write deterministically. The current approach uses a concurrent reader thread that polls is_set() while the trigger runs; the assertion fails if the worker.cancel blocks the event-set call. Real production cancel paths do their own join, so this guards against accidentally reordering the cascade.
