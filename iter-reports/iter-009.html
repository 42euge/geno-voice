      Notes:

      • DONE_OK trigger test exposed a real subtlety: time.monotonic() doesn't work for VirtualMicStream tests because pre-pushed audio is served in milliseconds. The VAD's 0.8s silence window never elapses by wall clock. Solution: inject a frame-aligned clock — same FrameClock pattern as iter-006. In production this is a non-issue since real PyAudio serves frames at audio rate.
      • A play_fn that respects cancel_event must yield between chunks (sleep, blocking I/O, anything). Otherwise the worker thread races through the play loop before the test can set the flag. The test fixture uses time.sleep(0.005); real audio playback blocks at audio rate so this happens naturally.
